|--------------|-------|--------|-----------|--------|

Всього: 3 запити, 287 kB передано, сторінка завантажилась за 18 ms.

Заголовки запиту index.html (вкладка Headers):
- Request URL: http://127.0.0.1:5500/index.html
- Request Method: GET
- Status Code: 200 OK
- Content-Type (у відповіді): text/html; charset=UTF-8

1. Адреса сторінки: http://127.0.0.1:5500/index.html.
   Складається з протоколу (http), хоста (127.0.0.1, тобто мій власний комп'ютер),
   порту (5500, на ньому працює Live Server) і шляху до файлу (/index.html).

2. Браузер зробив N запитів: спочатку index.html, потім, прочитавши HTML,
   знайшов тег <img> і окремо запросив logo.png. Ще один запит робить сам
   Live Server для автооновлення сторінки.

3. При неправильному шляху сервер не знайшов файл і повернув статус 404 Not Found.
   Замість картинки показався текст з атрибута alt.

4. DevTools змінює лише копію сторінки в пам'яті браузера (DOM), а не файл на диску.
   Після F5 браузер знову завантажує index.html з сервера, тому зміни зникають.

5. Клієнт - браузер, який надсилає запити. Сервер - Live Server на моєму комп'ютері (127.0.0.1:5500), який віддає файли.
